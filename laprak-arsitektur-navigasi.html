Arsitektur Navigasi

Named Routes & Bottom Navigation Bar

Aplikasi Mobile
Pendahuluan

Aplikasi mobile memiliki berbagai halaman yang saling terhubung untuk memudahkan pengguna dalam mengakses fitur yang tersedia. Oleh karena itu, sistem navigasi menjadi salah satu bagian penting dalam pengembangan aplikasi agar perpindahan antarhalaman dapat dilakukan dengan mudah dan terstruktur. Flutter menyediakan berbagai fitur navigasi, seperti Named Routes dan Bottom Navigation Bar, yang dapat digunakan untuk mengatur perpindahan halaman serta mempermudah pengguna dalam mengakses menu aplikasi.

Pada praktikum ini, dilakukan pengembangan aplikasi finansial menggunakan Flutter dengan menerapkan Named Routes dan Bottom Navigation Bar. Aplikasi yang dibuat mencakup halaman login, Dashboard, Riwayat Transaksi, dan Profil. Melalui praktikum ini, diharapkan dapat dipahami cara mengatur navigasi antarhalaman, menampilkan informasi pengguna berdasarkan input email, serta mengintegrasikan beberapa halaman ke dalam satu aplikasi yang lebih terstruktur dan mudah digunakan.

Tujuan

Praktikum ini bertujuan untuk:

  • Menerapkan Named Routes untuk navigasi terpusat dan rapi.
  • Membangun menu bawah (BottomNavigationBar) ala aplikasi modern.
  • Mengintegrasikan Dashboard, Riwayat, dan Profil dalam satu wadah.
Langkah Praktikum
1. Mendaftarkan Named Routes

Buka file main.dart. Hapus parameter home pada MaterialApp, lalu ganti dengan initialRoute dan routes.

  • Rute '/' akan menunjuk ke MainScreen (Layar ber-tab).
  • Rute '/add' menunjuk ke AddTransactionScreen.
2. Membuat penampung Tab (MainScreen)

Buat file main_screen.dart. Jadikan ia sebagai StatefulWidget karena tab yang aktif akan selalu berubah-ubah nilainya.

  • Siapkan variabel _selectedIndex.
  • Siapkan List berisi Widget (halaman-halaman) yang akan ditukar.
3. Merangkai BottomNavigationBar

Lengkapi method build di MainScreen.

Tugas Praktikum
1. Buatkanlah halaman Riwayat transaksi!

Halaman riwayat transaksi dibuat untuk menampilkan daftar transaksi yang telah disimpan dalam aplikasi.

2. Buatkanlah halaman profile yang berisi avatar, nama, email dan tombol logout.

Halaman profile dibuat untuk menampilkan informasi pengguna yang login, termasuk avatar, nama, email, dan tombol untuk logout.

3. Buatkan 1 halaman login yang berisi textfield email dan password kemudian tombol login.

Ketika tombol login di klik akan tampil halaman utama aplikasi dan menampilkan informasi email yang diinputkan oleh user.

Kesimpulan

Berdasarkan praktikum yang telah dilakukan, Named Routes dapat digunakan untuk mengatur navigasi antarhalaman agar lebih terstruktur, sedangkan Bottom Navigation Bar memudahkan pengguna berpindah antara halaman Dashboard, Riwayat Transaksi, dan Profil. Selain itu, pembuatan halaman login membantu memahami cara menerima input email dan password serta menampilkan informasi email pengguna pada halaman utama aplikasi.

Melalui praktikum ini, dapat dipahami bahwa penggabungan beberapa halaman dengan sistem navigasi yang tepat dapat membuat aplikasi finansial menjadi lebih terorganisasi dan mudah digunakan. Penerapan fitur-fitur tersebut juga menambah pemahaman mengenai penggunaan Flutter dalam membangun aplikasi mobile yang memiliki beberapa halaman dan fungsi yang saling terhubung.

Project Aplikasi Mobile

Pada project kali ini, kita diminta untuk menggabungkan semua praktikum yang telah dibuat mulai dari praktikum 1 sampai dengan praktikum 5. Dalam penggabungan ini terdapat beberapa file yang saya buat yang merupakan penggabungan dari praktikum-praktikum yang telah dikerjakan sebelumnya. File tersebut di antaranya sebagai berikut:

main.dart

Berfungsi sebagai penghubung antara keseluruhan file menjadi kesatuan yang bisa dijalankan.

database_helper.dart

Menghubungkan aplikasi dengan database.

widgets/formatters.dart

File formatter untuk keperluan widget.

services/auth_service.dart

Layanan autentikasi untuk login dan registrasi.

screens/add_transaction_screen.dart

Merupakan file yang menampilkan halaman untuk menambahkan data transaksi.

screens/dashboard_screen.dart

Merupakan file yang menampilkan menu dashboard.

screens/history_screen.dart

Merupakan file yang menampilkan halaman data Riwayat transaksi.

screens/login_screen.dart

Merupakan file yang memuat halaman login.

screens/main_screen.dart

Merupakan file yang menampilkan halaman utama setelah user login.

screens/profile_screen.dart

Merupakan file yang menampilkan halaman profil akun.

screens/register_screen.dart

Merupakan file yang memuat halaman pendaftaran user.

screens/Splash_screen.dart

Merupakan file yang bertujuan untuk menampilkan halaman pembuka ketika aplikasi pertama kali dijalankan.
